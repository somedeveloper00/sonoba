# Sonoba

**日本語** | [English](README.en.md)

![画面の文字が訳文に置き換わるデモ](docs/demo.webp)

<sub>映像は等速で、訳文は PC の中で動かした PLaMo 3 Translate 2B の生成物です。リアルタイムの訳文は普段は録画に写らないので、写るように変えた録画用のビルドで撮りました。ゲームの画面はデモ用に作ったものです。映画の場面とゲームの背景は Tears of Steel (CC BY 3.0 Blender Foundation | mango.blender.org) です。</sub>

Windows 用の常駐アプリです。画面の好きな範囲を OCR して、文字を訳文に置き換えて見せます。翻訳先は日本語、やさしい日本語、英語、韓国語、中国語から選べます。Google 翻訳の画像翻訳のように、訳文を元の文字の位置に重ねて表示します。処理はすべて PC の中で完結します。

**[Sonoba をダウンロード（zip）](https://github.com/paisu-supai/sonoba/releases/latest/download/sonoba.zip)**（Windows 11 用、72MB、いつも最新版）。以前のバージョンと変更点は [Releases](https://github.com/paisu-supai/sonoba/releases) にあります。

Built with PLaMo.

## 導入

対応 OS は Windows 11 です。インストールは要りません。Visual C++ ランタイムは zip に入っているので、別に入れなくても動きます。zip を好きなフォルダに展開して `sonoba.exe` を起動します。初回は案内が開き、表示の言語と翻訳モデルを選びます。案内に出るのは軽量と標準の大きさだけで、大きいモデルはあとで設定の「モデル」からダウンロードできます。PLaMo 3 Translate を選んだときは、ダウンロードの前に PLaMo コミュニティライセンスへの同意を求めます。同意するまで、PLaMo 3 Translate では翻訳できません。Hy-MT2 は同意なしで使えます。

設定とモデルは exe の隣の `data` フォルダに保存します。フォルダごと消せばアプリも消えます。翻訳モデルの保存先は、設定で別のフォルダに変えられます。更新は新しい zip の中身を上書きします。Program Files のように書き込めない場所に置いたときは、`%APPDATA%` と `%LOCALAPPDATA%` の `Sonoba` フォルダに保存します。自動起動を使っているときは、フォルダを消す前に設定でオフにしてください。

ダウンロードしたファイルなので、初回の起動で SmartScreen の警告が出ることがあります。「詳細情報」から「実行」を選ぶか、展開する前に zip のプロパティで「許可する」にチェックを入れてください。Smart App Control が有効な PC では、展開する前のこの操作が必要です。

## 使い方

| キー | 動作 |
| --- | --- |
| Ctrl+Alt+T | 範囲を選び、1 回だけ翻訳する |
| Ctrl+Alt+R | 範囲を選び、リアルタイムで翻訳し続ける。止めるのは Ctrl+Alt+X か、続けて 2 回押す |
| Ctrl+Alt+X | 翻訳を止めて訳文を消す |
| Ctrl+Alt+Q | 押している間だけ原文を見る |
| Ctrl+Alt+C | 訳文をクリップボードにコピーする。結果はカーソルの横に出る |

キーは設定で変えられます。マウスの中ボタンとサイドボタンも割り当てられます。キーごとに既定へ戻すことも、無効にすることもできます。ホットキーが止まるのは、設定画面でキーを選んでいる間だけです。

範囲はドラッグで選びます。ドラッグ中は範囲の外側に緑の線が出ます。ドラッグせずにクリックすると、白枠の付いたウィンドウ全体を選びます。Esc か範囲の外の右クリックで取り消せます。取り消すと、それまでの翻訳はそのまま続きます。範囲を選んでいるあいだは、設定の「緑の枠線」がオフでも、翻訳中の範囲を緑の線で囲みます。その範囲の中を右クリックすると、その範囲だけを消せます。範囲を選ぶ画面は閉じないので、続けて選び直せます。

範囲を選ぶ間は、画面の上にバーが出ます。翻訳元、翻訳先、リアルタイムのオンとオフをここで切り替えられます。

翻訳中にもう一度 Ctrl+Alt+T か Ctrl+Alt+R を押し、Shift を押しながらドラッグすると、範囲を追加できます。Shift を押しながらウィンドウをクリックすると、そのウィンドウ全体を足せます。字幕とチャット欄、ゲームとコメントビューアーのように、離れた場所や別のアプリを同時に翻訳できます。Shift を押さなければ、今の翻訳を止めて新しい範囲に置き換えます。

範囲はそれぞれ、選んだときのモードで動きます。バーのリアルタイムがオンで選んだ範囲はリアルタイムで、オフで選んだ範囲は 1 回翻訳です。1 回翻訳の範囲は、そのページが変わると、その範囲の訳文だけが消えます。範囲が複数のときは、ウィンドウを動かしても付いていきません。

タスクトレイの右クリックメニューの「一時停止」で、ホットキーも翻訳も止められます。ゲームのキーとぶつかるときに使います。リアルタイム翻訳は再開すると続きから動きます。

範囲を選ぶ画面でもう一度同じホットキーを押すと、前回と同じ範囲を翻訳します。ページをめくったあとの訳し直しは Ctrl+Alt+T を 2 回押すだけです。

訳文は段落ごとに元の文字の上に重なり、文字サイズ、背景色、文字色、太字は元の文字に合わせます。メニューや図の箱のように、同じ色で横一列に並んだラベルは、文字サイズと太字をそろえます。設定画面の見出しのように、同じ色で縦に 3 つ以上並んだラベルも、大きさが近ければ文字サイズをそろえます。訳文が長いときは、1 行なら右の空きへ、段落なら下の空きへ広げ、それでも足りなければ文字の幅を少し細くし、それでも足りなければ文字を小さくします。日本語の訳文は、カタカナ、漢字、英字が続くところの途中では折り返さず、助詞や送り仮名は前の語と同じ行に置きます。アイコン、入力欄の枠、画像などの文字以外の部分はそのまま見えています。写真やグラデーションの上の文字は、文字だけを周りの色で消して、縁取りを付けた訳文を重ねます。リアルタイムでは、訳文はそのままで後ろの絵が変わったときも、今の画面から文字を消し直します。写真や絵の上で読み取りに自信がない行は、格子などの模様とみなして訳しません。数字やコードのように訳が変わらないものは置き換えません。

選んだ範囲はその下のウィンドウに結び付きます。ウィンドウを動かすと訳文も一緒に動き、サイズを変えると訳し直し、最小化すると隠れます。1 回翻訳の訳文は、範囲の画面が大きく変わると自動で消えます。

選択中も翻訳中もキーボードのフォーカスを取らないので、アクティブウィンドウは変わりません。クリックやスクロールは訳文を通り抜けて下のウィンドウに届きます。

画面共有や録画に訳文を映すには、設定の「画面共有と録画にリアルタイムの訳文も映す」をオンにします。範囲が 1 つのウィンドウの中にあるときは、画面全体の共有と録画に訳文が映ります。Shift で足した範囲も、それぞれが 1 つのウィンドウの中にあれば映ります。ウィンドウを選んで共有するときは、元のウィンドウの代わりに「Sonoba 共有用 - プログラム名」（たとえば「Sonoba 共有用 - chrome」）を選びます。範囲を選んで翻訳を始めるとタスクバーに出るウィンドウで、元のウィンドウに訳文を重ねて映します。範囲のあるウィンドウごとに 1 つずつ出るので、ゲームとコメントビューアーのように、別々に取り込めます。それぞれには、そのウィンドウの中の範囲の訳文だけが映ります。画面の外に置くので、普段は目に入りません。

- Discord でこのウィンドウを選ぶと、元のアプリの音は乗りません。音も流すときは画面全体を共有します。
- OBS のウィンドウキャプチャでは、キャプチャ方法を「Windows 10 (1903 以降)」にします。BitBlt では黒く映ります。
- 最小化すると映らなくなります。翻訳を止めても、最後に翻訳したウィンドウを映し続けます。
- 元のウィンドウの前に別のウィンドウを重ねると、画面の訳文はそのウィンドウの下に隠れます。「Sonoba 共有用」には訳文がそのまま映ります。
- 同じプログラムのウィンドウが 2 つあるときは、名前の後ろに (2) が付きます。
- 1 つの範囲が複数のウィンドウにまたがるときと、デスクトップを選んだときは、画面をそのまま読むので、訳文はどの共有にも映りません。Shift で足した範囲のうち 1 つでもそうなっていると、全部の範囲が同じ扱いになります。「Sonoba 共有用」は前のウィンドウを訳文なしで映し続けます。デスクトップは映しません。

## 設定

タスクトレイのアイコンをダブルクリックすると、設定を開けます。設定画面は Windows 11 に標準で入っている WebView2 で表示します。

- 翻訳元と翻訳先: 範囲を選ぶときのバーと同じ設定
- 文体: おまかせ、です・ます調、だ・である調。おまかせでは原文の雰囲気に合わせる。PLaMo 3 Translate のときだけ効く
- 用語集: 決まった訳にしたい言葉の一覧。原文にその言葉があるときだけ使う
- 読み取る言語: 韓国語は最初から入っている。ロシア語、アラビア語、タイ語、ヒンディー語、タミル語、テルグ語は、選んでダウンロードすると読み取れるようになる。どれも削除できる
- 翻訳モデル: 選択、ダウンロード、削除、読み込み、アンロード、保存先の変更
- 実行方法: 自動、GPU のみ、CPU のみ
- GPU メモリ上限: 自動のときに、翻訳エンジンが使う GPU メモリの上限を選ぶ
- CPU スレッド数: 自動のときは PC の性能コアの数を使う。好きな数に減らせる
- ホットキー: 5 つの操作それぞれのキー。キーごとにリセットと無効化ができる
- 緑の枠線: 翻訳している範囲の外側に細い線を出す。画面いっぱいのウィンドウでは内側に出す。翻訳が終わったときに一瞬だけ太い線を出すこともできる。どちらも既定では切ってある
- 画面共有と録画: リアルタイムの訳文も Discord や Meet の画面共有と OBS の録画に映す。範囲が 1 つのウィンドウの中にあるときだけ効く。ウィンドウを選んで共有するための「Sonoba 共有用 - プログラム名」も、範囲のあるウィンドウごとに出す。既定では切ってある
- 訳文のフォント、太字、濃さ: 濃さを下げると元の画面が透けて見える
- 履歴: 最近の訳文と原文の一覧。開いているあいだに画面に出た訳も、すぐ上に足される。前に出た文がまた画面に出たときも、もう一度足される。タスクトレイの右クリックメニューの「履歴」からも開ける。検索とコピーができる。メモリにだけ持ち、アプリを終了すると消える。切ることもできる
- 自動起動: Windows の起動時に開始する。既定では切ってある。オンにすると、レジストリの `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` に `Sonoba` という名前で exe の場所を書き、サインインするとタスクトレイに常駐した状態で始まる。管理者権限は要らず、自分のアカウントだけに効く。オフにするとこの値を消す。zip を展開したフォルダで使うとき、フォルダの外に書くのはこの値だけ。フォルダを移動したら、オフにしてからオンにし直す
- 表示の言語: 日本語か英語。初回は Windows の言語に合わせる

既定の「自動」は GPU メモリに載る分を GPU で、残りを CPU で実行します。空きが十分なら全部 GPU に載り、GPU のない PC では CPU だけで動きます。GPU メモリの空きが少ないときは、軽い 0.8B に変えると速く動きます。

RAM の上限はありません。RAM の使用量はモデルの大きさと GPU に載せる量で決まるので、減らすには軽いモデルを選ぶか、GPU に載せる量を増やします。

アプリをもう一度起動すると、動いているほうの設定が開きます。`data` フォルダの `sonoba.log` には、起動した時刻と終わった理由を書き出します。異常終了したときは、その原因も書き出します。

## 対応言語

読み取れるのはラテン文字の言語（英語、フランス語、ドイツ語、スペイン語など）、中国語、日本語、韓国語です。韓国語の OCR モデル（13MB）は zip に入っています。

次の言語は、設定の「読み取る言語」で OCR モデル（1 つ 8MB）をダウンロードすると読み取れるようになり、ほかの言語と同じように自動で翻訳します。

- ロシア語、ウクライナ語、ブルガリア語、カザフ語など（キリル文字）
- アラビア語、ペルシャ語、ウルドゥー語など
- タイ語
- ヒンディー語、マラーティー語、ネパール語など（デーヴァナーガリー）
- タミル語
- テルグ語

小さい文字（9pt）では読み間違いが増えます。ヒンディー語、タミル語、テルグ語は、15pt の文字でも一部の字を読み違えました。ウクライナ語は Hy-MT2 の対応言語にはありますが、PLaMo 3 Translate の対応言語にはありません。ギリシャ語はどちらの翻訳モデルの対応言語にもないので、入れていません。

翻訳先の言語で書かれた文字には触りません。たとえば翻訳先がやさしい日本語なら、外国語だけをやさしい日本語に訳して、画面の日本語はそのまま残します。翻訳元を「日本語も翻訳」にすると、画面の日本語もやさしい日本語に書き換えます。やさしい日本語はモデルカードにない指定（`ja(easy)`）で、モデルのテンプレートと PFN の CLI が使っています。

翻訳先が英語のときは、ラテン文字だけの文を英語とみなして翻訳しません。

## モデル

| モデル | サイズ | 目安 |
| --- | --- | --- |
| PLaMo 3 Translate 0.8B | 0.6GB | 軽量。2B の 2 倍ほど速いが誤訳が増える |
| PLaMo 3 Translate 2B | 1.8GB | 標準 |
| PLaMo 3 Translate 8B | 5.3GB | 高品質 |
| PLaMo 3 Translate 31B | 19.5GB | 最高品質 |
| Hy-MT2 1.8B 軽量 | 0.8GB | 標準を unsloth が 3bit に小さくしたもの（UD-IQ3_XXS）。使うメモリは約 1.4GB。訳の質は標準より少し下がる |
| Hy-MT2 1.8B 標準 | 1.1GB | Tencent のモデル。Apache License 2.0 で、同意なしで会社でも使える。速さは 2B と同じくらいで、GPU メモリは約 1.7GB。文体の指定は効かない |

ほかのモデルも使えます。GGUF ファイルをモデルの保存先（既定は `data\models`）に置くと、設定の一覧に出ます。モデルの種類は、GGUF ファイルの中に書かれた名前で見分けます。そこで分からなければ、ファイル名で見分けます。PLaMo 3 Translate のファイルは、ほかのアプリが別の名前で置いたものでも PLaMo 3 Translate として扱い、ライセンスへの同意を求めます。Tencent が配っている Hy-MT2 のファイルは、中の名前が「1.8B」だけです。そのため Hy-MT2 は、ファイル名に `Hy-MT` が入っているものをそう扱い、モデルの説明どおりの文で依頼します。どちらでもないモデルには、モデル自身のチャットテンプレートで翻訳を依頼します。

モデルの保存先は、設定の「モデル」の「フォルダを選ぶ」で変えられます。ほかのアプリと同じフォルダや、別のドライブのフォルダも選べます。選んだフォルダの GGUF が設定の一覧に出て、ダウンロードもそのフォルダに保存します。保存先を変えても、前のフォルダのモデルは移動も削除もしません。OCR モデルは、保存先を変えても `data\models` に置きます。

ダウンロードを中止すると途中までのファイルが残り、次のダウンロードは続きから始まります。要らなければ「削除」で消せます。

## 測定値

RTX 4070 Ti と Core i7-13700F の PC で、PLaMo 3 Translate 2B を GPU で動かしたときの値です。0.8B の値は測ったものだけ並べて書きます。

| 項目 | 値 |
| --- | --- |
| 1 文の翻訳（モデルを読み込んだあと、範囲を決めてから表示まで） | 760×60 の範囲は約 0.2 秒（2B は 0.17〜0.28 秒、0.8B は 0.14〜0.23 秒）。1280×720 の範囲は約 0.5 秒（2B は 0.43〜0.76 秒、0.8B は 0.38〜0.54 秒）。同じ文をもう一度訳すときは、760×60 の範囲で約 0.13 秒 |
| リアルタイムの更新（字幕 2 行、文字が変わってから表示まで） | 約 0.8 秒（2B は 0.77〜0.87 秒、0.8B は 0.66〜0.83 秒）。大半は OCR の 0.5〜0.65 秒 |
| 図 1 枚の翻訳 | 2B は約 2 秒、0.8B は約 1 秒 |
| 画面が変わってから古い訳文が消えるまで | 約 0.04 秒 |
| 2000×1077 の設定画面、約 40 段落 | 最初の表示まで約 1 秒、全部で約 2 秒 |
| アプリを起動して最初の翻訳 | 約 3 秒 |
| アプリのメモリ（待機中） | 9MB |
| アプリのメモリ（動作中） | 約 90MB |
| 翻訳エンジンのメモリ（読み込み中） | 約 380MB |
| GPU メモリ（読み込み中） | 2B は約 2.1GB、0.8B は約 0.65GB |

OCR モデルは 60 秒使わないとメモリから外し、翻訳エンジンは 15 分使わないと止めます。アンロードはエンジンの停止なので、メモリも GPU メモリも全部空きます。

実行方法とエンジンの違いは次のとおりです（10 段落の翻訳、4 本同時）。

| 構成 | 時間 | RAM | GPU メモリ |
| --- | --- | --- | --- |
| 自動（既定、この PC では全部 GPU） | 0.68 秒 | 360MB | 2.15GB |
| 自動、GPU メモリ上限 1.5GB | 3.8 秒 | 1.0GB | 1.5GB |
| 自動、GPU メモリ上限 1GB | 6.4 秒 | 1.5GB | 1.0GB |
| CPU のみ（8 スレッド） | 7.5 秒 | 2.2GB | 0 |
| 参考: llama-server + CUDA | 0.6 秒 | 650MB | 2.35GB |
| 参考: Ollama（CUDA） | 0.66 秒 | 1.5GB | 2.3GB |

CPU に回す層が増えるほど遅くなるので、GPU メモリの上限は足りないときだけ使います。上限を付けると、配分を計算するぶん読み込みも約 3 秒長くなります。

## 仕組み

- 画面の取得は GDI の BitBlt で行います。別スレッドが 0.033 秒ごとに画面を見て、変化があれば OCR に渡します。OCR の最中でも変化に気づくので、古い訳文はすぐに消えます。範囲が複数のときは範囲ごとに読み、絵が変わった範囲だけを読み直します。一覧が上下にずれただけのとき（チャットに新しいコメントが来たときなど）は、訳文も一緒にずらし、新しく出た行だけを訳します。
- 画面共有と録画に映す設定がオンのときは、範囲ごとに、その範囲のあるウィンドウを PrintWindow で読みます。重ね表示を読まずに済むので、訳文を録画から隠さなくてよくなります。範囲の上に別のウィンドウが重なっても、その下の元のウィンドウの文字を読みます。画面の訳文は、0.05 秒ごとに前のウィンドウの形で切り抜きます。
- 「Sonoba 共有用」は、元のウィンドウと重ね表示の写しを DWM のサムネイルとして重ねたウィンドウです。写しは画面の外に置き、切り抜かず、画面の取り込みからも外しません。写しのうち、そのウィンドウの中の範囲の部分だけを、範囲ごとにサムネイルにします。描くのは DWM で、Sonoba は 0.05 秒ごとに位置と大きさを合わせるだけです。
- OCR は PP-OCRv6 small を rten で CPU 実行します。モデルは exe に埋め込んであります。韓国語などの言語別のモデル（PP-OCRv5）が `data\models` にあるときは、読み取りに自信がない行と、行の幅に比べて読めた字が少なすぎる行だけ、言語別のモデルでも読みます。言語別のモデルが読んだ結果にそのモデルの言語の文字があれば、そちらを使います。言語別のモデルは、直前に読めた言語から順に試し、十分な自信で読めたらそこでやめます。アラビア語は、モデルが左から右の順で出す字を、右から左の順に並べ直します。スレッド数は PC の性能コアの数に合わせます。検出枠の中に 1 文字半ほどの空白があれば、メニューの項目や表のセルとみなして、そこで分けて読みます。明るい絵が重なって空白が見つからないときも、読み取った字と字の間が、ふつうの字の間隔の 4 倍以上離れていれば分けます。アクセント付きの字を読んだ行は、上下に少し余白を足して読み直し、確かなほうを使います。枠の端に近い英語の l が、アクセント付きの i に読まれることがあるためです。検出枠の中のインクを行ごとに調べて、文字だけの範囲、背景色、文字色、太字を求めます。文字にふち取りや光があるときは、それを除いた文字の高さから大きさを決めます。写真や絵の上では、文字色に近い画素だけで高さを測り、文字から離れた小さな点は数えません。折り返した行は、同じ欄のすぐ上の行につなげて段落にします。横に並んだ欄があっても、欄ごとにつなげます。上の行と左端、中央、右端のどれもそろっていない行は、つなげません。ゲームのメニューの行がセリフにつながらないようにするためです。最後の行が短く、g や y のように下へ出る字がないときは、枠の高さではなく、字の種類から求めた文字サイズで上の行と比べます。
- 翻訳は llama-server を起動して HTTP で依頼します。約 240 文字ずつ 1 行 1 段落でまとめ、4 本同時に流し、1 行できるごとに表示します。まとめた段落どうしが文脈になり、直前のまとまりの原文も参考として渡します。ラベルのような 3 語までの短い段落は、まとめずに 1 つずつ頼みます。まとめると、モデルが行をつなげたり順番を変えたりして、訳が別の場所に入ることがあるためです。1 つずつ頼むときは、近くのラベルを文脈として渡します。単独では「Exit」が「出口」になりますが、メニューのほかの項目と一緒なら「終了」になります。
- ウィンドウの移動は WinEvent で受け取り、OCR をせずに訳文を動かします。
- 重ね表示は透過色つきの最前面ウィンドウです。

## 制限

- リアルタイムの訳文は、既定ではスクリーンショットや録画に写りません。OCR が自分の訳を読まないようにするためです。設定の「画面共有と録画にリアルタイムの訳文も映す」をオンにすると、範囲が 1 つのウィンドウの中にあるときは写ります。1 回翻訳の訳文は写りますが、まれに写らないことがあります。範囲が複数のときは、1 回翻訳の範囲も写りません。
- リアルタイムでは写真やグラデーションの上の文字を単色の四角で覆います。
- 縦書きと回転した文字は読めません。
- 長辺が 1,600 ピクセルを超える範囲は縮小してから読むので、小さい文字は読みにくくなります。範囲が複数のときは、範囲ごとに数えます。
- 1 回翻訳の訳文は、画素の 8% 以上が変わると消えます。少しのスクロールでは残ることがあります。画面に追従させるにはリアルタイムを使います。
- 排他フルスクリーンのゲームと、著作権保護のある動画には対応していません。

## ビルド

Rust（MSVC）が必要です。

```bash
cargo build --release
```

翻訳エンジンは `engine\llama-server.exe` を exe の隣から探し、なければ Ollama に同梱のものを使います。配布用の zip は次のコマンドで作ります。llama.cpp の公式ビルド（Vulkan 版）を取得して同梱し、韓国語の OCR モデル（`models\korean_PP-OCRv5_mobile_rec.onnx`）を `data\models` に入れます。

```bash
powershell -ExecutionPolicy Bypass -File scripts/package.ps1
```

画面に触らずに表示を確かめるには、画像に訳文を描いて保存します。

```bash
RENDER_IN=in.png RENDER_OUT=out.png cargo test render_picture -- --ignored --nocapture
```

言語別の OCR モデルのテストは、設定からダウンロードしたモデルのあるフォルダを指定して実行します。

```bash
OCR_MODELS=data/models cargo test reads_the_scripts_that_come_as_downloads -- --ignored --nocapture
```
